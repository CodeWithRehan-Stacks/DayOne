# 🧮 Python Calculator

A simple calculator made with Python.  
This project performs basic mathematical operations like addition, subtraction, multiplication, and division.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ❌ Divide by zero protection
- 💻 Beginner-friendly code

```bash

```

3. Run the program

```bash
python calculator.py
```

## 🧠 Code Example

```python
num1 = float(input("Enter first number: "))
operator = input("Enter operator (+, -, *, /): ")
num2 = float(input("Enter second number: "))

if operator == "+":
    print(num1 + num2)
```
